# 语音需求书（v1）

## 定位

桌面助手型的“会说话”。**用户不说话**，没有麦克风输入；她按触发条件主动用日语播报，配中文字幕。

## 本期范围

做：**语音生产与播放链路**（文本 → TTS → 队列 → 播放 → 嘴型 → 字幕）。
不做：定时提醒、番茄钟、久坐、唤醒词、麦克风常听、语音插话、中文音色。

## 触发（本期只保留这三类）

| 触发 | 说明 | 默认 |
|---|---|---|
| 手动 | 托盘/右键菜单「说句话」、快捷键 | 开 |
| 启动问候 | 启动后主动说一句 | 开 |
| 长时间无操作自言自语 | 连续 N 分钟无键鼠活动后说一句 | **关**（可开） |

不做时间/事件驱动的提醒——那是下一期。

## 内容生成

**模板为主，LLM 只润色。**

1. 程序先选出模板与事实字段，例如：`{{问候}}，{{当前时段}}。`
2. 模板渲染成一条完整日语句，数字、时间、专名**由程序填入**。
3. 需要变化时，把渲染好的句子交给本地 LLM（qwen3:1.7b）做**同义改写**，约束：
   - 只改语序与措辞，**不得改动任何数字、时间、专名**
   - 输出必须仍是日语，长度不超过原句 1.5 倍
   - 改写失败或校验不过 → 直接用模板原文
4. 校验规则：改写后的句子必须包含原句里的所有数字与专名；否则回退。

## 播放链路

```
文本 → 按标点分句（≤60 字） → 逐句 TTS → 队列 → 播放 → 嘴型 → 字幕
```

- TTS：本地 `speech/server.py`，GPU 实测 0.25 s/句（短句）。
- 首句目标：**≤1.5 s 出声**（合成 + 播放启动）。
- 后续句子在前一句播放时并行合成。
- 嘴型：`ParamMouthOpenY` 由 WAV 包络驱动；停止/静音/结束时归零。
- 字幕：日语原文 + 中文翻译（翻译失败只显示原文，不阻塞播放）。

## 打断

- 触发停止（快捷键或点击）后：**当前这句播完即停**，不硬切、不叠加下一句。
- 停止后队列清空，嘴型归零。

## 验收

| 项 | 标准 |
|---|---|
| 连续播报 | 脚本触发 10 次，全程自动，无残留音频 |
| 首句延迟 | ≤1.5 s（GPU 合成 + 播放启动） |
| 内容一致 | 字幕与语音逐句对应，无跳句/漏句 |
| 打断 | 停止后当前句播完即静音，队列为空 |
| 事实不漂 | 时间/数字经 LLM 润色后不变 |
