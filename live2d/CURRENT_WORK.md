# 瑠璃乃桌宠：当前目标与制作顺序

最终目标：Windows Live2D 桌宠，本地 Ollama 对话，使用已有 Style-Bert-VITS2 日文语音模型并驱动嘴型。当前工作集中在美术材料与动作质量。

## 当前进度

最新为 [正脸基础动态 Live2D](FRONT_DYNAMICS_V034.md)。之前修好的 33 个正脸部件保留，新增 5 个口腔部件，完成 7 个有效参数：左右眨眼、口型、身体侧摆、呼吸及左右大马尾。附 8 秒待机、两组大马尾物理和 12 秒实际 SDK 运行预览。静态对比、动作隔离、连续播放、源工程重开导出和 Linux 桌宠检查通过。

直接加载运行包的 `runtime/Rurino_Front_Dynamics_v034.model3.json`；源工程可直接打开 cmo3。外部待机/物理配置随包附带，由脚本添加，并非 cmo3 内置动画项目。清单见 [metadata/front-dynamics-v0.3.4.json](metadata/front-dynamics-v0.3.4.json)。此前 [正脸刘海修复](FRONT_FRINGE_V034.md) 与 [侧视动作原型](BODY_HAIR_V034.md) 全部保留。

## 接下来的制作顺序

1. 在动态正脸上继续改善闭眼线和大马尾隐藏区、边缘接缝；保持正常轻摆可用。
2. 绑定真实左右转头和抬低头：远侧眼宽、眼距、鼻嘴、脸型同步，不以整脸拉伸冒充透视。
3. 补头部倾斜、眼球跟随、身体前后仰，以及逐缕刘海和两条小马尾物理。
4. Windows 实机验收，然后联调本地 Ollama、已有音色和实时口型。

当前侧摆是腰部旋转，未完成躯干三维转向。仅有基础闭眼；大马尾大幅摆动仍暴露材料接缝。没有 Windows、Ollama 或语音服务联调验收。

## 必须保留的用户要求

- 造型参照 [原视频](https://www.youtube.com/watch?v=ltAEA_Lq5Js)。结构为头顶、刘海、一对小双马尾、一对大双马尾；组内按发流逐缕处理，不做方块裁切。
- 保持中间刘海连续与眉毛独立，保护眼睛和皮肤颜色。
- 正面不能使用侧脸嘴；脸型与五官运动幅度匹配，检查转头眼距。
- 真实的独立透明发片与静态检查不能冒充已完成的 Cubism 网格、关键形或物理。
