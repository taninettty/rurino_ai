## 接下来的制作顺序

1. 制作连续眨眼、眼睑/虹膜裁切与嘴型，让新工作稿先具备基础表情及说话条件。
2. 校准已有正面 / 左右 / 抬低头 / 组合视角材料：眼距、远侧眼宽、鼻嘴位置与脸型同步，不能用整脸拉伸或镜像冒充转头。
3. 在已完成的四马尾、腰部侧倾与基础物理上，继续身体前后仰、头顶/刘海/鬓发/细长发的局部变形和跟随；检查根部遮挡及组合极限。详见 [身体动作与头发联动](BODY_HAIR_MOTION_PLAN.md)。
4. 新模型已通过本地桌宠加载检查；完整头身动作就绪后做 Windows 实机验收，再联调 Ollama、已有音色和嘴型。

上述整套动作仍待完成。当前已验证四马尾、腰部侧摆及其物理联动；真实转头、头部/身体俯仰和其余头发动作未做。v0.3.3 是旧运行测试稿，不代表新工程的功能。

## 必须保留的用户要求

- 造型参照 [原视频](https://www.youtube.com/watch?v=ltAEA_Lq5Js)。结构为头顶、刘海、一对小双马尾、一对大双马尾；组内按发流逐缕处理，不做方块裁切。
- 保持中间刘海连续与眉毛独立，保护眼睛和皮肤颜色。
- 正面不能使用侧脸嘴；脸型与五官运动幅度匹配，检查转头眼距。
- 真实的独立透明发片与静态检查不能冒充已完成的 Cubism 网格、关键形或物理。
