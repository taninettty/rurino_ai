# 瑠璃乃桌宠：当前目标与制作顺序

最终目标：Windows Live2D 桌宠，本地 Ollama 对话，使用已有 Style-Bert-VITS2 日文语音模型并驱动嘴型。当前工作集中在美术材料与动作质量。

## 当前可用材料

最新是 [头发独立黑色描边](HAIR_INDEPENDENT_INK_V034.md)：53 层 PSD，9 个主要发片分别有可开关黑线，另有 3 个眼前发梢补线层。原 41 层保留，默认显示左视图头部与原半身。前一版为 [整头静态修整与装配](WHOLE_HAIR_STATIC_V034.md)。四类静态收尾已落实：头顶 / 连续刘海；小双马尾；大双马尾及截断发梢；整头遮挡、针孔及接缝检查。

眉毛独立。原 29 个脸部 / 眼睛 / 身体等相关图层保留，睁眼、半闭眼、闭眼可以切换。头顶与中间刘海仍共用一张连续材料，没有强拆。隐藏面与画布外末端含本地推断补画，不是不可见原画恢复；此前 LibTV 服务阻断，本轮未使用它生成。

权威路径和 SHA256 见 [材料清单](metadata/current-materials-v0.3.4.json)。旧 134 层输入 PSD 放在素材包中供回退，新 PSD 不叠加历史候选。身体仍是原腰部裁切半身，不是完整全身。

## 接下来的制作顺序

1. 在 Cubism 中建立头部、头顶 / 刘海、左右大小马尾、鬓发及长细发的网格与变形器，整理上述共用区的控制关系。
2. 校准已有正面 / 左右 / 抬低头 / 组合视角材料：眼距、远侧眼宽、鼻嘴位置与脸型同步，不能用整脸拉伸或镜像冒充转头。
3. 制作并检查身体左右侧摆、前后仰及头发跟随；先完成根部遮挡和极限姿态，再调整物理。详见 [身体动作与头发联动](BODY_HAIR_MOTION_PLAN.md)。
4. 导出新的运行模型，接入 Windows 桌宠；再验收 Ollama 对话、已有音色与嘴型。

以上动作未在本轮实现或验收。v0.3.3 仍是旧运行测试稿，不能当作新头发已绑定。

## 必须保留的用户要求

- 造型参照 [原视频](https://www.youtube.com/watch?v=ltAEA_Lq5Js)。结构为头顶、刘海、一对小双马尾、一对大双马尾；组内按发流逐缕处理，不做方块裁切。
- 保持中间刘海连续与眉毛独立，保护眼睛和皮肤颜色。
- 正面不能使用侧脸嘴；脸型与五官运动幅度匹配，检查转头眼距。
- 真实的独立透明发片与静态检查不能冒充已完成的 Cubism 网格、关键形或物理。

历史步骤与早期失败候选见 [装配前记录](WORK_HISTORY_BEFORE_WHOLE_HAIR_V034.md)，其中“最新/下一步”只代表当时状态。
