# 瑠璃乃桌宠：当前目标与制作顺序

最终目标是 Windows 上可用的瑠璃乃 Live2D 桌宠，支持本地 Ollama 对话，使用仓库已有的 Style-Bert-VITS2 日文语音模型，并驱动嘴型。当前优先解决用户指出的造型和转头问题。

用户于 2026-10-28 补充后续目标：身体左右侧摆、前倾后仰，头发随头部及身体运动流畅跟随。当前逐缕重绘须为这些动作预留隐藏根部和遮挡余量。具体制作与检查要求见 [身体动作与头发联动](BODY_HAIR_MOTION_PLAN.md)。这些是待制作目标，不表示动作已经实现。

## 必须遵守的造型约束

- **最新用户确认的头发结构：[头顶、刘海、一对小双马尾、一对大双马尾](HAIR_STRUCTURE_V034.md)**。先分清这四组及根部连接，再在组内逐缕拆分。不得继续将小双马尾笼统当作短后发分条；头顶与刘海的共用部分暂未正确分开。

- 以原视频 https://www.youtube.com/watch?v=ltAEA_Lq5Js 为身份、脸型、眼部和头发遮挡参考，使用 LibTV 制作与补画。
- 保留确认过的正面形象、非对称刘海及默认微笑；侧脸嘴不能直接贴到正脸上。
- 转头不能靠整张正面脸拉伸或镜像。左右分别重画，再将正确关键形用于部件网格。
- 眼距、远侧眼宽度、鼻嘴位置和脸颊轮廓必须一起检查。不能只平移五官，导致脸型跟不上而显得肿。
- 虹膜应独立于眼白和眼睑，运动时不得露底变色；头发要按真实前后遮挡拆分，并补齐被遮住的区域。

## 接下来的顺序


**用户最新调整：中间刘海可以不拆；先把眉毛单独分开，再开始补全各个头发。当前以此顺序为准，覆盖之前“先全部拆完再统一修整”。**

1. 眉毛独立分离后，按头顶/刘海、小双马尾一对、大双马尾一对逐组补全缺口、隐藏根部和遮挡区域。中间刘海保持连续，不再沿用 C/D 的临时上端切线；按运动需要决定是否细拆，不以层数作为完成度。已完成左右眉下局部补接，接着检查头顶共用根部、小马尾扎点、大马尾被身体遮住的部分和鬓边连接。LibTV 生成受阻时不重复派发，本地编辑须如实记录。
2. 按确认的方向结构拆分脸皮、耳朵、刘海、后发及上下视角眼部，补齐隐藏区域，继续与正面配准。正面部分闭眼外眼角睫毛问题保留为后续修订项。
3. 在 Cubism 建立转头和表情参数，检查上下左右及四角组合，再与眨眼、视线、张嘴叠加检查，避免脸型与五官幅度脱节和遮罩漏色。
4. 制作身体左右侧摆及前倾后仰的关键形，处理肩颈、领口、衣服和长发的透视与遮挡；先单独检查身体，再组合头部动作。
5. 按发束长度和位置绑定头发跟随与物理：发根稳定、发中逐步弯曲、发梢延迟回摆，短发与长发分别调整。检查身体与头部动作叠加、换向、停止及参数极限，修复穿插、露底和异常抖动。
6. 导出可运行模型，接回 Windows 桌宠，完成麦克风、Ollama、现有角色语音和口型联动验收。

继续沿用 `live2d-handoff` 分支和 v0.3.4 草稿保存制作成果；未验收的新素材不能标成新的可运行版。
