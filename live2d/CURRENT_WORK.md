# 瑠璃乃桌宠：当前目标与制作顺序

最终目标是 Windows 上可用的瑠璃乃 Live2D 桌宠，支持本地 Ollama 对话，使用仓库已有的 Style-Bert-VITS2 日文语音模型，并驱动嘴型。当前优先解决用户指出的造型和转头问题。

## 必须遵守的造型约束

- 以原视频 https://www.youtube.com/watch?v=ltAEA_Lq5Js 为身份、脸型、眼部和头发遮挡参考，使用 LibTV 制作与补画。
- 保留确认过的正面形象、非对称刘海及默认微笑；侧脸嘴不能直接贴到正脸上。
- 转头不能靠整张正面脸拉伸或镜像。左右分别重画，再将正确关键形用于部件网格。
- 眼距、远侧眼宽度、鼻嘴位置和脸颊轮廓必须一起检查。不能只平移五官，导致脸型跟不上而显得肿。
- 虹膜应独立于眼白和眼睑，运动时不得露底变色；头发要按真实前后遮挡拆分，并补齐被遮住的区域。

- v0.3.4 有 76 层正面表情 PSD，以及独立重绘的左右侧向参考。另有两份各 10 层侧向眼部 PSD；完整侧向头部拆层、配准和新 Cubism 绑定尚未完成。
- 转头眼部的实际采纳状态见 [眼部记录](TURN_EYES_V034.md)，当前选用图见 [转头记录](TURN_REDRAW_V034.md)。失败候选不当作已修复成果。
- 本轮完成[侧向眼部分层与实际 PSD 小幅视线检查](SIDE_EYE_MATERIALS_V034.md)。眼白无蓝绿色虹膜残留，原虹膜颜色保留；虹膜/眼睑边缘仍需收整，不代表侧向眨眼或连续转头已验收。
- 桌宠聊天程序和语音模型已有仓库资料；Windows 实机的麦克风→Ollama→语音→口型整链路仍须验收。

## 接下来的顺序

1. 已完成本轮左右远侧眼局部修订及视频对照；后续拆层时持续检查眼距和透视，不把静态检查等同于绑定验收。
2. 先清理侧向虹膜浅色残边和眼睑碎边，补画半闭眼、闭眼及刘海下的眼睑；继续拆分脸皮、耳朵、刘海、后发，并与正面配准。
3. 在 Cubism 建立转头和表情参数，检查左/正/右与上下角度，以及眨眼、视线、张嘴的组合，避免拉伸脸型和遮罩漏色。
4. 导出可运行模型，接回 Windows 桌宠，完成麦克风、Ollama、现有角色语音和口型联动验收。

继续沿用 `live2d-handoff` 分支和 v0.3.4 草稿保存制作成果；未验收的新素材不能标成新的可运行版。
