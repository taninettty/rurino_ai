# 瑠璃乃桌宠：当前目标与制作顺序

最终目标：Windows Live2D 桌宠，本地 Ollama 对话，使用已有 Style-Bert-VITS2 日文语音模型并驱动嘴型。当前工作集中在美术材料与动作质量。

## 当前进度

当前阶段为 [正脸刘海清理与网格接入](FRONT_FRINGE_V034.md)：修补两片刘海眼部缺口，去除右侧夹入肤色，补回头顶外侧分割缝，加入独立线层并调整贴脸发束遮挡。33 层 PSD、可编辑 cmo3 与运行包已完成本轮验证。实际 SDK 渲染、网格覆盖、保存重开导出一致性和 Linux 桌宠检查通过。仍是静态正脸，27 个默认参数未绑定；贴脸发束、长前发、大马尾及支撑层继续检查。

[轮廓修复、四马尾与身体侧摆](BODY_HAIR_V034.md) 是此前的左视图动作原型，保留其 60 层材料、四马尾、腰部侧摆和物理作为参考与回退。此前将该侧视图当作主要交付，没有同时补齐正脸基础；现在优先补正面。侧视图功能尚未迁入正脸模型。

## 当前可用材料

最新文件及 SHA256 见 [刘海清理清单](metadata/front-fringe-v0.3.4.json)。此前 [小马尾清理版](FRONT_SMALLTAILS_CLEAN_V034.md)、[正脸基础](FRONT_NEUTRAL_V034.md) 和 [侧视材料清单](metadata/current-materials-v0.3.4.json) 保留。侧视图的动作不代表正脸已有相同功能。

正脸已修复眼白盖住上睫毛和虹膜的问题，没有移动虹膜中心或改变原色。两侧小马尾已补全隐藏区并加独立轮廓；刘海已完成本轮缺口和轮廓修补；贴脸发束、长前发、大马尾和支撑层仍需检查，脸型比例本轮未重设计。身体仍为腰部裁切半身。

## 接下来的制作顺序

1. 对照原视频校准正面脸型、五官和头发结构；逐缕补全正脸头发与黑线，以正面为默认姿态。
2. 按新眼开口制作连续眨眼、眼球裁切和嘴型，不能直接复用旧闭眼图冒充绑定。
3. 校准正面 / 左右 / 抬低头 / 组合角度：眼距、远侧眼宽、鼻嘴位置与脸型同步，不能用整脸拉伸或镜像冒充转头。
4. 将侧视图原型中验证过的发根固定、共享颜色与黑线的变形方法应用到正面，继续身体侧摆、前后仰及头发物理。见 [身体动作与头发联动](BODY_HAIR_MOTION_PLAN.md)。
5. 完整动作就绪后做 Windows 实机验收，再联调 Ollama、已有音色和嘴型。

正脸尚无上述动态功能；v0.3.3 和侧视图原型的功能都不能当作它已有的功能。本轮没有 Windows 或语音服务联调。

## 必须保留的用户要求

- 造型参照 [原视频](https://www.youtube.com/watch?v=ltAEA_Lq5Js)。结构为头顶、刘海、一对小双马尾、一对大双马尾；组内按发流逐缕处理，不做方块裁切。
- 保持中间刘海连续与眉毛独立，保护眼睛和皮肤颜色。
- 正面不能使用侧脸嘴；脸型与五官运动幅度匹配，检查转头眼距。
- 真实的独立透明发片与静态检查不能冒充已完成的 Cubism 网格、关键形或物理。

历史步骤与早期失败候选见 [装配前记录](WORK_HISTORY_BEFORE_WHOLE_HAIR_V034.md)，其中“最新/下一步”只代表当时状态。
