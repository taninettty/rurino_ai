# 瑠璃乃桌宠：当前目标与制作顺序

最终目标是 Windows 上可用的瑠璃乃 Live2D 桌宠，支持本地 Ollama 对话，使用仓库已有的 Style-Bert-VITS2 日文语音模型，并驱动嘴型。当前优先解决用户指出的造型和转头问题。

## 必须遵守的造型约束

- 以原视频 https://www.youtube.com/watch?v=ltAEA_Lq5Js 为身份、脸型、眼部和头发遮挡参考，使用 LibTV 制作与补画。
- 保留确认过的正面形象、非对称刘海及默认微笑；侧脸嘴不能直接贴到正脸上。
- 转头不能靠整张正面脸拉伸或镜像。左右分别重画，再将正确关键形用于部件网格。
- 眼距、远侧眼宽度、鼻嘴位置和脸颊轮廓必须一起检查。不能只平移五官，导致脸型跟不上而显得肿。
- 虹膜应独立于眼白和眼睑，运动时不得露底变色；头发要按真实前后遮挡拆分，并补齐被遮住的区域。

## 接下来的顺序

1. 已有九方向绘画参考；先统一各方向的身份、脸型体积、头部尺度和颈部位置，建立部件与遮挡对应，不把静态绘画参考当成连续转头已完成。
2. 按确认的方向结构拆分脸皮、耳朵、刘海、后发及上下视角眼部，补齐隐藏区域，继续与正面配准。正面部分闭眼外眼角睫毛问题保留为后续修订项。
3. 在 Cubism 建立转头和表情参数，检查上下左右及四角组合，再与眨眼、视线、张嘴叠加检查，避免脸型与五官幅度脱节和遮罩漏色。
4. 导出可运行模型，接回 Windows 桌宠，完成麦克风、Ollama、现有角色语音和口型联动验收。

继续沿用 `live2d-handoff` 分支和 v0.3.4 草稿保存制作成果；未验收的新素材不能标成新的可运行版。
