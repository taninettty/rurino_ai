# 用户确认的头发结构与拆分顺序

用户确认主要分为四组：**头顶、刘海、一对小双马尾、一对大双马尾**。这四组是解读原画、划分层级的依据，组内再按真实发束细分；不预设发束数量。

| 主组 | 现有素材对应与问题 | 下一步 |
| --- | --- | --- |
| 头顶 | 头顶轮廓及共用发根目前混在左右 Bang 层和待整理边界内，尚未正确独立 | 先辨认与刘海、发饰、小马尾根部的连接，不以横向直线切下 |
| 刘海 | 左右额前发束及其遮挡关系；现有 Bang/Cheek 命名不代表边界已正确 | 沿发尖向上追实际轮廓；贴脸发的连接归属不清处暂记待定 |
| 小双马尾一对 | 原 ShortRearHair_ImageLeft/Right 及 L01–03、R01–05 分段；此前被笼统称作短后发 | 左右各作为一条小马尾，先确定扎点、整体外轮廓与前后层次，再分内部发束 |
| 大双马尾一对 | 原 RearTail_ImageLeft/Right_Visible 及相关遮挡边界 | 左右各作为一条大马尾，分清连续走向与被身体遮住的部分；原画底边之外的发梢不凭空认定 |

鬓边单束、胸前细长单束和共用根部需依据连接关系归组，不因为当前文件名就直接认定归属。花饰是附件，眉线、皮肤和衣领不是发束。

制作顺序：四组结构定位 → 逐组辨认根尖与前后遮挡 → 按真实边界拆出可见发束 → 最后统一补根、去残留、修接缝和调整形状 → 再做 Cubism 绑定与动作验证。
